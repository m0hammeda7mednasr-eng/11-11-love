# 11:11 — You're My Favorite Wish ❤️

موقع مفاجأة رومانسي تفاعلي بمناسبة 11/11.

## الأقسام
- شاشة سوداء: هزّي الموبايل لفتح المفاجأة، مع زر بديل.
- صورتنا الرئيسية + 9 صور ذكريات.
- رسالة حب و11 سبب للحب.
- أربعة أسئلة تفاعلية وجايزة مفاجأة مضحكة.
- زر موسيقى: يحتاج إضافة ملف mp3 خاص بكم في `assets/our-song.mp3`.

## تشغيل GitHub Pages
1. افتح Settings → Pages.
2. تحت Build and deployment اختر **Deploy from a branch**.
3. اختر `main` ثم `/(root)` واضغط Save.
4. رابط الموقع بعد نجاح النشر: https://m0hammeda7mednasr-eng.github.io/11-11-love/

## تحديث الصور
استبدل `assets/couple.jpg` بالصورة الرئيسية، و`assets/memory-1.jpg` حتى `assets/memory-9.jpg` بصور الذكريات.

## ملاحظات
بعض أجهزة iPhone تشترط إذن الحركة من Safari، لذلك أضفنا زر فتح بديل. الصوت يبدأ بعد أول تفاعل بسبب قيود التشغيل التلقائي في المتصفحات. الأسئلة الحالية تجريبية. هذا الريبو عام، لذلك الصور الموجودة فيه عامة.
